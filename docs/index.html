The context layer for code

Find the right file before you start digging.

Contexting builds a live map of your codebase — paths, symbols, and optional language-aware synonyms — so people and AI agents can search by intent instead of guessing filenames.

A first session

Maya joins an unfamiliar project.

She does not know whether the thing she needs lives in services/, handlers/, or a folder someone named six months ago. Ten minutes later, she has a map, a useful search habit, and a watcher running beside her editor.

01

Install

Put ctxt on the path.

Use a release archive for a quick start, or install from Go if your toolchain is already set up.

go install github.com/ktappdev/contexting/cmd/ctxt@latest

Check the binary before moving on: ctxt version or ctxt --version.

02

Initialize

Build the map once.

From the root of the project, init walks the tree, respects ignore rules, extracts symbols, and saves a snapshot under .ctxt/.

ctxt init .
ctxt status

The first run creates a starter .ctxt/ctx_config.toml for settings you want to keep.

03

Search by intent

Ask for the job, not the filename.

Search combines paths, basenames, symbols, and optional synonyms. Start with the language you would use to describe the work.

ctxt search-hints "authentication middleware"
ctxt search-hints "session timeout" --explain

Use --json when another tool needs structured results.

04

Stay current

Let the map follow the work.

watch keeps an in-memory index fresh while you code and exposes a local endpoint for live queries. Stop it with Ctrl+C to flush the snapshot.

ctxt watch . --verbose

Live LLM enrichment is opt-in with --llm-on-watch; query logging is off by default.

Under the hood

A map is more useful than a pile of filenames.

Contexting separates indexing from asking. The expensive work happens once; searches stay small, local, and fast. The same index powers the CLI, watch mode, and MCP integrations.

01 ⌁

Source tree

Walk files and folders while applying built-in, .gitignore, and config ignores.

02 { }

Symbols

Extract functions, classes, types, variables, and constants with AST or regex fallbacks.

03 ✦

Synonyms

Optionally expand code names into the concepts people actually search for.

04 ▣

Index

Persist a versioned JSON tree in .ctxt/ctx_index.json; load it into memory for watch.

05 ↗

Ranked hints

Return explainable paths to the CLI, scripts, and AI assistants through MCP.

What gets matched

One query, many signals.

Exact filenames are strongest, followed by path segments, synonyms, and symbols. A confidence-gap cutoff keeps weak matches from crowding out the useful ones.

exact filename+15
directory basename+12
synonym exact+8
symbol exact+8
path segment+4

Know what leaves the machine

Local search by default. LLMs are a choice.

The index and normal search run locally. When synonym generation is enabled, Contexting can send names plus context such as extracted symbols and JavaScript/TypeScript imports to the configured OpenAI-compatible endpoint. Watch-mode LLM calls and query logging are opt-in.

Before you begin

The practical questions.

Most projects can start with the three-command path. These details help you choose the right mode once the index becomes part of your workflow.

Does Contexting work without an API key?

Yes. Symbol extraction and path matching still work. You only lose LLM-generated synonym expansion. Use --offline when you want that behavior to be explicit.

What is the difference between init and watch?

init creates or refreshes the on-disk snapshot. watch loads it into memory, applies file changes as they happen, serves live search, and writes the updated snapshot when it shuts down gracefully.

Can it search file contents too?

Concept search is based on indexed paths, symbols, and synonyms. Add --hybrid to let ripgrep provide a content fallback when the indexed results are sparse.

What does it ignore?

Built-in ignores are combined with the project’s .gitignore and extra config patterns. Dot-prefixed paths and symlink entries are skipped by default; negated ignore rules do not re-include a path.

How large can a project be?

Initial indexing is guarded at 10,000 files after ignores. Larger projects should narrow the index with additional ignore patterns rather than receive a misleading partial snapshot.

Which languages are supported?

The current extractors cover Go, Python, JavaScript, TypeScript, Rust, Svelte, Astro, Vue, and Ruby, with tree-sitter or regex fallback depending on the language and extractor mode.
