## Methodology

### Engines
- **contexting:** Uses precomputed index with symbols, synonyms, and path scoring. Returns ranked results.
- **find:** Walks filesystem and matches tokens against filenames. Returns alphabetical results.
- **grep:** Walks filesystem and matches tokens against file contents. Returns alphabetical results.
- **combined:** Union of find and grep results. Returns alphabetical results.

### Common behavior
- All engines respect contexting ignore rules
- find/grep return alphabetical results (no ranking)
- contexting returns ranked results (scoring: path, basename, synonym, symbol matchers)

### Metrics
- **Hit@k:** Correct file appears in top k results
- **Recall:** Correct file appears anywhere in results
- **Tokens:** Total characters in results / 4 (heuristic for output size)
- **Noise Ratio:** 1.0 - (relevant results / total results). Lower is better.

### Found field
- Correctly checks against expect_any for all engines
- Bug fixed this session: previous runs incorrectly reported Found: yes when correct file wasn't in results

### Test environment
- Index load time: 0ms (one-time cost, not included in per-query times)
- All queries run sequentially
- Results aggregated by category and overall
